# 🛍️ Amazon Reviews Sentiment Analysis

This project performs sentiment analysis on Amazon product reviews using Python and Natural Language Processing (NLP). It processes raw review text, cleans and prepares the data, and applies machine learning techniques to classify customer sentiments.

## 📌 Features

- Read and preprocess Amazon review data
- Clean and tokenize text
- Remove unnecessary characters and stopwords
- Convert text into machine-readable features
- Train a sentiment classification model
- Evaluate model performance
- Predict sentiment for new reviews

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
- NLTK
- Matplotlib
- Seaborn

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/amazon-reviews-sentiment-analysis.git
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run

Open the notebook:

```bash
jupyter notebook Amazon_Reviews.ipynb
```
